# My Task Manager

This is a simple Task Manager web application built using **HTML, CSS, and Vanilla JavaScript**.

The goal of this project is to understand basic DOM manipulation and user interaction without using any external libraries or frameworks.

## Features
- Add a new task
- Mark a task as completed
- Delete a task
- Disable the “Add Task” button when input is empty
- Show total tasks and completed tasks count

## Tech Stack
- HTML  
- CSS  
- JavaScript (Vanilla)

## How to Run
1. Clone or download this repository  
2. Open `index.html` in any modern web browser  

This project is part of a JavaScript assignment for the **Incubation Program – Sankey Solution**.
